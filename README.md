# retro-games

Repositório de aprendizagem de desenvolvimento de jogos, como hobby. Sem intenção de publicação.

## Objetivo

Aprender os fundamentos de programação de jogos (game loop, deteção de colisões, gestão de estado, input handling, matemática de jogos) a partir de recriações de clássicos de arcade, por ordem de complexidade crescente. Cada jogo é uma pasta própria neste repositório.

Motivação: storytelling e mecânicas de jogo, não mercado ou publicação.

## Estrutura

Cada jogo tem a sua própria pasta na raiz do repositório, com o código e assets desse jogo isolados:

```
retro-games/
  pong/
  breakout/
  asteroids/
  ...
```

## Fases

**Fase 1: JavaScript, Canvas API pura**

Sem frameworks de jogos (sem Phaser). Recriação de clássicos de arcade, sequência prevista por ordem de dificuldade:

1. Pong
2. Breakout
3. Asteroids
4. Space Invaders / Phoenix
5. Donkey Kong
6. Paperboy
7. Chase HQ

Mais jogos a acrescentar ao longo do tempo. Fase propositadamente longa antes de qualquer tentativa de jogo próprio.

**Fase 2: Godot 4.x, GDScript**

Só arranca depois da Fase 1 estar consolidada. Foco em jogos isométricos, inspirados em Sexy Brutale, Little Big Adventure, Crusader, Cyclone.

## Perfil técnico de partida

Nível intermédio em JavaScript, zero experiência prévia em programação de jogos e em matemática de jogos (vetores, trigonometria, física). Background em edição de vídeo profissional e alguma experiência antiga em 3D Studio Max.

## Ferramentas

Editor: VSCode.
Plataforma alvo de interesse a prazo: PC via Steam.
